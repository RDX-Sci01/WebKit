[RDX-FORK](https://rdx-sci01.github.io/WebKit/)

The payloads themselves therefore don't necessarily need to be downloaded from the web interface.

They can remain locally inside: `/data/ps5_autoloader/`


`autoload.txt` controls the payload execution sequence.

Example:

!4000
ftpsrv-ps5-0.19.elf
!4000
shadowmountplus.elf
!4000
kstuff.elf
!4000
elf-arsenal.elf
